# Как продолжить QuestFlow в Claude Code

## 1. Открыть проект в Claude Code
Вариант А (приложение): «+» рядом с полем ввода → «Add folder» → выбрать папку QuestFlow в «Документах» → начать новую сессию.
Вариант Б (Терминал): открыть Терминал и выполнить по очереди:

    cd ~/Documents/QuestFlow
    claude

При первом запуске Claude Code сам прочитает файл CLAUDE.md в корне проекта: там память проекта, твои правила и карта кода.

## 2. Запустить приложение
Двойной клик по файлу «Запустить QuestFlow.command» в папке проекта (при первом запуске ставит зависимости под Mac).

## 3. Файлы, на которые я опираюсь
- CLAUDE.md — память проекта (читается автоматически)
- docs/ROADMAP.md — план по этапам
- docs/antigravity/user-requests.md — все 65 твоих запросов из Antigravity
- docs/antigravity/chat-transcript.md — весь чат целиком
- docs/antigravity/checkpoints.md — 19 сводок контекста
- docs/antigravity/raw/transcript_full.jsonl — полный оригинал без сокращений
- docs/antigravity/artifacts/ — планы и задачи (implementation_plan, blind_focus_timer_plan, task, walkthrough)

## 4. Промпты (копируй целиком)

### Старт сессии
Прочитай CLAUDE.md, docs/ROADMAP.md и docs/antigravity/user-requests.md. Запусти npm run build и проверь, что проект собирается. Коротко скажи по-русски, что понял про проект и в каком он состоянии, и предложи первый шаг из ROADMAP.

### Этап 1: чистка кода
Выполни этап 1 из docs/ROADMAP.md. Сначала сведи все ключи localStorage с префиксом questflow_ в один файл констант. Потом разбей TogglTimerBar.tsx и App.tsx на части без изменения поведения. После каждого шага запускай npm run build, делай отдельный коммит и отмечай галочку в ROADMAP. Правила из CLAUDE.md не нарушай, особенно про таймер, список покупок, Big Data и воскрешение задач. Пуш в GitHub не делай.

### Этап 2: редизайн
Начни этап 2 из docs/ROADMAP.md. Используй скилы ui-ux-pro-max и design-system. Сначала предложи три разных направления дизайна с коротким описанием палитры, шрифтов и вида экрана «Сегодня» на телефоне и на Mac. Код не пиши, пока я не выберу направление.

### Продолжить после перерыва
Прочитай CLAUDE.md и docs/ROADMAP.md, посмотри git log и git status. Скажи, на чём мы остановились, и продолжи со следующего незавершённого пункта плана.

### Сохранить договорённости
Обнови CLAUDE.md: добавь всё важное, о чём мы договорились в этой сессии, и отметь выполненное в docs/ROADMAP.md.

### Отправить на GitHub (только когда решишь)
Проверь npm run build, покажи git status и список коммитов, которые ещё не на GitHub, и после моего «да» сделай git push в master.
