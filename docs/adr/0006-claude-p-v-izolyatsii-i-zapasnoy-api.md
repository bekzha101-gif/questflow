# 0006. Анализ через `claude -p` в изоляции, запасной путь через API

## Контекст
Пользователь хочет, чтобы анализ шёл через его аккаунт Claude без отдельного платного API; тариф Max. Нагрузка: ~1 анализ в день, 1 в неделю, 1 в месяц и разбор скриншота сна. Сервер работает без присмотра.

## Решение
Основной путь — CLI `claude -p` с JSON-выводом и подпиской Max. Вызов идёт в изоляции (`CLI_ISOLATION_ARGS`): без инструментов и без MCP; это добавил ремонт, служебная часть запроса стала ≈ 3,1K токенов и 5 с. Если CLI недоступен или упёрся в лимит, срабатывает запасной путь, Anthropic API, но только если пользователь сам вписал `ANTHROPIC_API_KEY`. Если не отвечает ни то ни другое, `analyze` возвращает `null`: бот шлёт отчёт без AI-раздела и повторяет попытку позже (каждые 5 минут).

## Почему
- Только API отвергнуто: пользователь просил обойтись без отдельного платного API; запасной путь стоит ≈ $3–10 в месяц.
- Edge Functions отвергнуты: подписку оттуда не вызвать (см. 0005).
- `claude -p` с инструментами и MCP отвергнут: анализу нужен только текст из промпта; инструменты и MCP добавляют служебные токены и время, а бот остаётся без присмотра.
- Падать при недоступности Claude отвергнуто: вечерний разговор и запись данных не должны зависеть от внешнего сервиса.

## Последствия
- Расход идёт из общего пула подписки Max вместе с ручной работой пользователя; при упоре в лимит анализ откладывается.
- Без ключа API запасного пути нет: отчёт придёт позже и без анализа.
- CLI должен быть установлен и авторизован под тем же Windows-пользователем.
- Claude видит только то, что передано в промпте (срез за 30 дней и память `ai_memory`); он не может сам дочитать данные.
