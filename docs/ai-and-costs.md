# AI-аналитик и голос: как устроено и сколько стоит

Коротко: анализ делает Claude **в твоём аккаунте** (подписка Max) через программу `claude` на этом компьютере. Голосовые распознаёт faster-whisper на видеокарте RTX 2060. Сверх подписки это **$0 в месяц**. Если когда-нибудь впишешь ключ Claude API, он станет запасным путём: примерно **$3–5 в месяц**.

## Что и когда вызывает Claude

| Когда | Что | Вызовов в месяц |
|---|---|---|
| Каждый вечер, кроме пятницы | разбор дня: что хорошо, что лучше, как поднять продуктивность | ~26 |
| Скриншот Sleep Cycle | Claude читает со скриншота время сна и качество | до ~26 |
| Воскресенье | отчёт недели и шаги на следующую неделю (кнопка «Принять») | 4–5 |
| Последний день месяца | отчёт месяца, итог целей, выводы в память | 1 |

Всего около 55–60 вызовов в месяц. В каждый анализ уходит срез за 30 дней: фокус, задачи, цели, сон, БАДы, привычки, оценки, заметки, каналы, доход. Кроме среза, туда же идут прошлые выводы из таблицы `ai_memory`: 6 месяцев, 4 недели и 7 дней. Так Claude «помнит прошлое» и может написать: «в прошлом месяце при сне меньше 6 ч оценка падала».

## Сравнение вариантов

| | Подписка Max: `claude -p` (сейчас) | Claude API (запасной) | Supabase Edge Functions |
|---|---|---|---|
| Где работает | этот компьютер, 24/7 | этот компьютер | облако Supabase |
| Оплата | входит в подписку | по токенам, ≈ $3–5/мес | API ≈ $3–5/мес + платное распознавание голоса ≈ $1–2/мес |
| Нужен ключ | нет: используется вход Claude пользователя Administrator | `ANTHROPIC_API_KEY` в `server/.env` | ключ API в секретах Supabase |
| Читает скриншоты | да (проверено: тестовая картинка «7h 32m, 85%» прочитана как 452 мин и 85%) | да | да |
| Голос | Whisper на видеокарте, бесплатно | так же | видеокарты нет — только платный сервис |
| Разговор с состоянием | да (состояние в `bot_settings.conversation`) | да | неудобно: функции живут секунды, нужен внешний таймер |
| Скорость | ~20–40 с на анализ (CLI грузит свой контекст) | ~5–15 с | ~5–15 с |
| Риск | лимиты Max общие с обычной работой | расход денег, если что-то зациклится | всё сразу: платно, сложнее, нет GPU |

**Вывод:** основной путь — подписка через `claude -p`, как ты и хотел. API подключается только при вписанном ключе. Edge Functions не подходят: там нельзя вызвать Claude по подписке и нет бесплатного Whisper.

## Влияние на лимиты Max

- Лимиты Max общие: то, что тратит бот, вычитается из того же пула, что и твоя работа в Claude Code и claude.ai (окна по 5 часов и недельный лимит).
- Один вечерний анализ по объёму похож на одно среднее сообщение в Claude Code. Каждый вызов `claude -p` загружает твой общий контекст Claude Code (глобальный CLAUDE.md, хуки, скиллы). В проверочном вызове со скриншотом это было около 86 тыс. токенов из кеша и 31 тыс. новых, по прайс-листу ≈ $0.27. Деньгами это не списывается, но в лимит подписки идёт.
- Итого за месяц ≈ 60 таких вызовов. Это заметно меньше одного рабочего дня в Claude Code. Анализ идёт вечером, когда ты обычно не работаешь, и в окно с основной работой не попадает.
- Если лимит исчерпан, бот не ломается. Итог дня уходит **без раздела Claude** с припиской «пришлю позже», а повтор запланирован: через 30 минут, потом всё реже, до 8 попыток. С ключом API бот сразу пробует запасной путь.

## Запасной Claude API: стоимость

Сколько стоит месяц, если весь анализ идёт через API, по ценам Sonnet ($3 за 1 млн входных токенов, $15 за 1 млн выходных):

| Что | Токенов на вызов (вход / выход) | Вызовов | ≈ $/мес |
|---|---|---|---|
| День | 20–30 тыс. / 1,5 тыс. | 26 | 2,3–3,0 |
| Неделя | 30–40 тыс. / 2 тыс. | 4–5 | 0,5–0,8 |
| Месяц | 40–60 тыс. / 2 тыс. | 1 | 0,15–0,2 |
| Скриншот сна | 2 тыс. / 0,1 тыс. | 26 | 0,2 |
| **Итого** | | | **≈ $3–5** |

Модель для API задаётся переменной `ANTHROPIC_MODEL`, по умолчанию `claude-sonnet-4-5`. Ключ вводится в `npm run setup` или вписывается в `server/.env`. Он нигде не печатается.

## Голос (faster-whisper)

- Работает на RTX 2060, бесплатно, без интернета (модель лежит в кеше Hugging Face).
- Установка один раз: `powershell -ExecutionPolicy Bypass -File server\stt\install.ps1`. Скрипт создаёт `server\stt\.venv` и ставит `faster-whisper` и CUDA-библиотеки. Модель по умолчанию — `medium`, около 1,5 ГБ; на этом компьютере она уже скачана.
- Проверено на этом компьютере (модель medium, CUDA): короткое голосовое расшифровывается за 15 с, из них большая часть — загрузка модели. Минута речи — ориентировочно до 20 с.
- Если Whisper не установлен или упал, бот отвечает «Не получилось распознать голосовое. Напиши, пожалуйста, текстом» и остаётся на том же вопросе: ничего не теряется.
- Настройки (необязательно) в `server/.env`: `WHISPER_PYTHON` — путь к Python с faster-whisper, `WHISPER_MODEL` — small, medium или large-v3-turbo, `WHISPER_DEVICE` — cuda или cpu.
