# Вечерний разговор

Владелец отвечает голосом (Remote Control или приложение Claude). Пиши по-русски, коротко, просто:
он не программист. Один вопрос за раз, без списков вариантов на полэкрана. Пропуск («дальше»,
«не знаю») — идём дальше. Весь разговор около 5 минут.

## Данные

Из `C:\Users\Administrator\svoi\questflow\server`:

- `npm run qf --silent -- evening [YYYY-MM-DD]` — день (что уже заполнено), БАДы, привычки, открытые задачи, цели месяца и шаги, план на завтра, напоминания по видео.
- `npm run qf --silent -- apply <файл.json>` — записать. Действия (кроме действий каналов из навыка `kanaly`):

| Действие | Поля |
|---|---|
| `patch_day` | `date`, `patch`: `sleepMin`, `sleepQuality` (%), `supplements` (имена), `score` (1–10), `why`, `note`, `goodBetter`, `waterOk` |
| `mark_habits` | `date`, `taskIds` (id привычек, которые выполнены) |
| `update_task` | `taskId`, `done?`, `progressPct?`, `dropReason?` |
| `update_goal` | `goalId`, `add?` (прибавилось, для числовых) или `set?` (новый %) |
| `add_goal_step` | `goalId`, `weekIndex`, `title` |
| `set_plan` | `date` (завтра), `mainTask`, `mainTaskId?` |
| `save_ai_memory` | `period`, `periodKey`, `summary`, `facts?` |
| `finish_report` | `date` — в самом конце: отчёт закрыт, награда за Big Data |

Записывай после каждого ответа (маленьким файлом), чтобы прерванный разговор не терял данные.
Дата — сегодняшняя по Бишкеку (`date` из `evening`). После полуночи и до 05:00 разговор — за вчера.

## Вопросы по порядку

Пропускай то, что уже заполнено в `day`.

1. **Сон.** «Сколько спал и качество по Sleep Cycle?» (скриншот — прочитай с картинки).
2. **БАДы.** «Что пил из БАДов?» — назови список `supplements`.
3. **Оценка дня.** «Оценка дня от 1 до 10 и почему?»
4. **Хорошо и лучше.** «Что сделал хорошо и что мог сделать лучше?»
5. **Привычки.** Назови привычки, спроси, какие выполнены → `mark_habits`.
6. **Задачи.** Только 3–5 главных из `openTasks`: сделана, сколько %, или брошена и почему.
7. **Цели.** По активным целям месяца: сколько прибавилось.
8. **Видео и каналы.** Покажи `reminders`: что просрочено, что выходит завтра, срочное, каналы без плана.
   Спроси: «Что выложил сегодня? Что сдвинулось? Что выходит завтра?». Изменения — навыком `kanaly`.
9. **План на завтра.** «Главная задача на завтра?» → `set_plan`.
10. `finish_report`.

В пятницу (день восстановления) пропусти задачи и цели, спроси, как отдохнул.

## Анализ

После вопросов — анализ дня: 3–5 строк по данным (`npm run qf --silent -- snapshot day`):
что получилось, что мешает, один совет на завтра. Цифры только из данных, ничего не выдумывать;
мало данных — так и скажи. Сохрани вывод: `save_ai_memory` (`period: day`, `periodKey` = дата).

- **Воскресенье:** ещё итог недели (`snapshot week`) и шаги к целям: 1–3 шага на следующую неделю
  для каждой активной цели. Владелец говорит «да» или правит → `add_goal_step`
  (`weekIndex` — номер следующей недели месяца, как в `goalSteps`). `save_ai_memory` `period: week`.
- **Последний день месяца:** итог месяца (`snapshot month`), `save_ai_memory` `period: month`.
