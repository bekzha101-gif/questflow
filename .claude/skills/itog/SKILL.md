# Итог дня, недели, месяца

1. Данные: из `C:\Users\Administrator\svoi\questflow\server` —
   `npm run qf --silent -- snapshot day|week|month [YYYY-MM-DD]` (30 дней контекста, прошлые выводы
   в `memory`, факторы влияния, здоровье).
2. Ответ по-русски, коротко, с цифрами и датами из данных:
   - 1–2 предложения итога;
   - что получилось (2–4);
   - что мешает (2–4);
   - что сделать (2–4 конкретных шага).
   Пятница — день восстановления, её не ругать. Мало данных (меньше 10 дней с оценкой) — прямо
   сказать «мало данных», без выдуманных причин. Ты не врач: без диагнозов и лекарств.
3. Неделя: предложи 1–3 шага на следующую неделю для каждой активной цели. После «да» →
   `add_goal_step` (формат и запись — в навыке `vecher`).
4. Сохрани вывод: `save_ai_memory` (`period`, `periodKey` = дата, `YYYY-Www` или `YYYY-MM`,
   `facts` — устойчивые связи вроде «при сне < 6 ч оценка ниже на 2»).

Тот же анализ есть на сайте: раздел «Здоровье» → кнопки «Анализ дня / недели / месяца»
(делает домашний сервер, ответ приходит на сайт).
