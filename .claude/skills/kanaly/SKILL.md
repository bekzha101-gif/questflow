# Каналы голосом

Владелец говорит голосом (расшифровка приложения Claude) или пишет. В названиях бывают ошибки
распознавания: ищи самое похожее имя канала или видео. Полный доступ без ограничений, но перед
удалением канала или видео спроси «удалить …? да/нет».

## Инструмент

Из папки `C:\Users\Administrator\svoi\questflow\server` (собран через `npm run build`):

- `npm run qf --silent -- state` — каналы (статус, Transformer, следующее видео, видео в работе и выложенные за 7 дней) и напоминания.
- `npm run qf --silent -- reminders [YYYY-MM-DD]` — просрочено, выходит сегодня и завтра, срочные, активные каналы без плана.
- `npm run qf --silent -- apply <файл.json> --dry` — показать, что поменяется; без `--dry` — записать.

Файл действий клади в scratchpad. Формат — массив объектов (проверка в `server/src/cli/actions.ts`):

| Действие | Поля |
|---|---|
| `add_channel` | `name`, `niche?`, `status?`, `transformer?` |
| `update_channel` | `channelId`, `name?`, `status?`, `color?` (#rrggbb), `niche?`, `transformer?`, `pausedUntil?`, `abandonReason?` |
| `delete_channel` | `channelId` (только после «да») |
| `add_video` | `channelId`, `title`, `stage?`, `publishDate?`, `urgent?` |
| `move_video` | `videoId`, `stage` |
| `rename_video` | `videoId`, `title` |
| `set_publish_date` | `videoId`, `publishDate` (YYYY-MM-DD или null) |
| `set_urgent` | `videoId`, `urgent` |
| `delete_video` | `videoId` (только после «да») |
| `add_income` | `date`, `amountUsd`, `channelId?`, `source?` |

Статусы: `active` = Веду, `planned` = Запущу, `paused` = Пауза (с `pausedUntil`), `abandoned` = Забросил.
При смене статуса цвет ставится сам (веду — зелёный, запущу — синий, пауза — жёлтый, забросил — серый);
`color` — только если владелец сам назвал цвет.
Этапы: `editing` Монтаж, `cover` Обложка и заголовок, `review` Проверка, `published` Выкладка
(выложено — награда начисляется сама, один раз на видео).

## Порядок

1. `state`, найди каналы и видео по словам владельца.
2. Собери действия, `apply --dry`, покажи список коротко.
3. Записывай сразу, если команда однозначная. Переспроси, если не уверен, о каком канале или видео речь, и всегда перед удалением.
4. После записи — одна строка «Готово: …». Сайт обновится сам.

## Цепочка «домино»

Каждый шаг запускается только после «да» владельца. Канал сайта связан с проектом через поле
`transformer` (видно в `state`).

1. **Монтаж.** Видео на этапе «Монтаж», владелец говорит «да, монтаж» → запусти отдельную сессию
   в `C:\Users\Administrator\transformer` (start_session, initiation `user_asked`, свой worktree не нужен).
   Бриф: канал `<transformer slug>` (`channels/<slug>/`), видео «<название>», дата выхода, сделать монтаж
   по правилам канала до финала на Drive. После финала скажи владельцу и переведи видео в `cover`.
2. **Обложка и заголовок.** Сессия в `C:\Users\Administrator\photo`: обложка в стиле конкурента ниши
   (папка `plans/<ниша>`), 2–3 варианта, не дороже $0.65 на видео, улучшать по отзыву владельца.
   Папки photo: bugx → `BugX`, chessbattle → `ChessBattle`, scifi-inside → `Star Wars` / `Far Far Away`,
   backstory-trump → `The Backstory`, war-machine-anatomy → `War Machine Anatomy`,
   washington-receipts → `Washington Receipts`. Нет папки — спроси владельца.
   Заголовок — Title Case. После выбора → `review`.
3. **Проверка.** Владелец смотрит видео. «Проверил» → готово к выкладке, дата — `set_publish_date`.
4. **Выкладка.** Выкладывает владелец. «Выложил» → `move_video` в `published`.

Новые цепочки владелец добавит позже: каждая — «этап → какой проект запускать».

## Каналы владельца

Имена на сайте — это имена каналов владельца, а не ниш. Связь с нишами Transformer уже записана в поле
`transformer`. Новые каналы (HomeDiscover, TomSmith, Astrovía) появятся, когда владелец купит
аккаунты и даст им номера: тогда `add_channel` со `status: planned` и `transformer`.
