# ⚔️ QuestFlow: Gamified Productivity Super-App
> Гибрид **Todoist** (структура и задачи), **Habitica** (RPG-геймификация и награды) и **ShortsFlow** (свайп-фокус и тайм-блокинг) с интеграцией Google Календаря и поддержкой MCP-агентов.

---

## 🌟 Ключевые Возможности

### 1. 📱 Flow Shorts Mode (Интерфейс в стиле ShortsFlow / Reels)
- **Полноэкранный вертикальный фокус-спринт**: на экране только одна ключевая задача.
- **Интерактивный Pomodoro-таймер**: встроенный секундомер / 25-минутный таймер с аудио-тиками и сигналами.
- **Сочные эффекты**: анимации частиц конфетти, аркадные звуковые эффекты начисления золота, опыта и урона по боссу.
- **Быстрые действия**: свайп между карточками (`↑`/`↓`), отложить на 15 мин, разбить на подзадачи с AI.

### 2. 🏰 Habitica RPG Геймификация
- **Профиль Героя**: Уровень, полоска Опыта (EXP), полоска Здоровья (HP), баланс Золота и Стрики дней.
- **Классы Героев с пассивными перками**:
  - 🧙‍♂️ **Маг**: +25% EXP за все квесты
  - ⚔️ **Воин**: +30% Урона по Боссу за задачи P1
  - 🗡️ **Ловкач (Rogue)**: +35% Золота со всех задач
  - 🌿 **Целитель**: +50% эффективности Зелий Здоровья
- **Привычки (+/-)**: Полезные дают EXP/Золото, вредные наносят урон по HP.
- **Дэйлики (Ежедневки)**: Растущие стрики дисциплины с бонусами к золоту.
- **Магазин Таверны**:
  - Реальные награды (1 час видеоигр, поход в кафе, покупка гаджета).
  - Игровые артефакты (Зелья восстановления HP, Свитки x1.5 EXP, Щиты стрика).
- **Рейд на Сезонного Босса**:
  - «Пожиратель Времени» (1000 HP) теряет здоровье при закрытии любых важных задач.

### 3. 📋 Todoist Ядро Продуктивности
- **Умный быстрый ввод (Quick Add `⌘K`)**: распознает даты, время, длительность, теги и приоритеты (например: `Смонтировать ролик завтра в 16:00 #shorts p1 45m`).
- **Иерархия проектов**: Входящие, Shorts & Контент, Разработка, Здоровье, Жизнь.
- **Приоритеты P1-P4**: Цветовое кодирование и автоматический расчет наград.
- **Чеклисты подзадач** с прогресс-баром.

### 4. 📅 Синхронизация с Google Календарём
- **2-Way Time-Blocking**: Интерактивная 24-часовая сетка дня, где задачи отображаются как временные слоты.
- **Экспорт `.ICS`**: Мгновенное скачивание файла расписания для Google Calendar, Apple Calendar и Outlook.
- **Webcal фид**: Прямая подписка по ссылке.
- **Google OAuth 2.0 API**: Готовая панель настройки Client ID.

### 5. 🤖 MCP (Model Context Protocol) Сервер & AI Квест-Мастер
- **AI Декомпозиция**: Превращает абстрактную сложную цель в 3 последовательных микро-квеста со сбалансированными наградами.
- **Файл `mcp_server.py`**: Позволяет AI-ассистентам (Antigravity, Claude Desktop) создавать задачи, проверять статы героя и закрывать квесты через естественный диалог.

## 🚀 Запуск Приложения

- **На ноутбуке / ПК**: [http://localhost:5173/](http://localhost:5173/)
- **На смартфоне** (в одной локальной сети Wi-Fi): `http://192.168.31.14:5173/`
- **PWA Режим**: В Safari на iOS нажмите *"Поделиться" -> "На экран 'Домой'"*, на Android в Chrome нажмите *"Установить приложение"*.

---

## 📱 Мгновенная Синхронизация Телефон ↔ Ноутбук
1. Откройте приложение на обоих устройствах.
2. Нажмите кнопку **«Телефон ↔ Ноутбук»** в шапке.
3. Введите 6-значный код сопряжения или откройте скопированную ссылку сопряжения (`?syncCode=XXXXXX`).
4. Все действия (закрытие квестов, урон по боссу, трата золота) синхронизируются в реальном времени!

---

## 🔌 Подключение MCP Сервера к Antigravity / Claude Desktop

Добавьте следующую секцию в ваш конфиг MCP (`claude_desktop_config.json` или настройки Antigravity):

```json
{
  "mcpServers": {
    "questflow": {
      "command": "python3",
      "args": [
        "/Users/bakyt/.gemini/antigravity/scratch/questflow/mcp_server.py"
      ]
    }
  }
}
```
