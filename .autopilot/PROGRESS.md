## Известные баги

- Очки бота и сайта в одной строке: одновременное начисление может потеряться; сайт и бот могут закрыть один день дважды
- Отстающие часы устройства: база молча отбрасывает правку (`002_questflow2.sql:19-33`)
- Кеш не разделён по пользователям: при смене аккаунта неотправленные правки уйдут в чужое облако
- Команда монтажёров из старого браузера не переносится (kv `legacy:questflow_team_v1`)
- Очистка localStorage снаружи (DevTools) при открытой вкладке не даёт чистого листа: данные в памяти вкладки записываются обратно при следующей правке. Сброс — через само приложение
