## Что должно заработать

Раздел «Каналы» показывает все каналы карточками: статус цветом (зелёный «Веду», жёлтый «Пауза до <даты>» — сама возвращается в «Веду», красный «Заброшен» с причиной, серый «Архив»), частота (2/день, 1/день, 1 раз в 2 дня), время монтажа, последняя публикация, следующее видео и **что делать сейчас** (`channelTodo`). Название редактируется. Видео идут по этапам Монтаж → Проверка → Опубликовано, в карточке чек-лист: контент-план, заголовок, превью, монтаж, выкладка; «Опубликовано» — после всех галочек. Старые видео на «Сценарий/Озвучка» переехали в «Монтаж». Расписание: кнопкой видно ближайшие даты по каждому каналу; `remindersFor` (не больше 3 в день, «завтра видео на X — запусти монтаж сегодня») готова для сервера. 5 каналов Бакыта из сидов на месте, у AGENT CODE задача «сменить текст на 2 превью».
