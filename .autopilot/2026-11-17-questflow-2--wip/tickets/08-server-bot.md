## Что должно заработать

В папке `server/` — Node 22 + TypeScript сервис. `npm run setup` в окне терминала пошагово объясняет, как создать бота в @BotFather, просит токен, service-role ключ Supabase, id владельца в Supabase и (необязательно) ключ Claude API, проверяет каждый и пишет в `server/.env` (git-ignored); `.env.example` — только имена. Бот (grammY, long polling) отвечает только владельцу: первый `/start` привязывает chat id в `bot_settings`, чужим — «бот приватный». Расписания по Asia/Bishkek: 8:00 (кроме пятницы) — короткое сообщение без вопросов: главная задача дня и первый блок; каждые 30 с — проверка `timer_state`: «пора на отдых», «отдых закончился», «ты проработал Xч Yм» (≤ 60 с после события, один раз); напоминания о публикациях через `remindersFor` (не больше 3 в день); будильники здоровья из `health_alarms`; в пятницу — тишина; четверг вечером — «завтра восстановление»; 03:00 — бэкап всех таблиц в `server/backups/` (хранить 60 дней). Точки вызова для вечернего разговора и отчётов (21:00, 22:00, воскресенье, конец месяца) зовут функции из `server/src/conversation/` — в этом таске это заглушки с понятным текстом, их наполняет таск 09. `scripts/install-service.ps1` создаёт задачу Планировщика Windows «при запуске системы» под текущим пользователем, `run.ps1` перезапускает процесс при падении (≤ 1 мин). `docs/server.md` — как установить и перезапустить.

## Критерии приёмки

- [ ] `npm run setup` проходит до первого сообщения в Telegram (с подменой Telegram в тесте); ни одного секрета в git
- [ ] Чужой chat id получает «бот приватный» и ничего больше (тест)
- [ ] Расписание по Бишкеку: утро 8:00 не в пятницу, четверг-вечер, пятница — ноль сообщений (тест с подменой времени)
- [ ] Окончание блока или отдыха → сообщение один раз (тест на `notified_end`)
- [ ] Напоминаний о публикациях не больше 3 в день (тест)
- [ ] Ночной бэкап пишет файл и удаляет старше 60 дней
- [ ] `install-service.ps1` создаёт задачу автозапуска; процесс поднимается после убийства ≤ 1 мин
- [ ] `npm test` и `npm run build` в `server/` зелёные
