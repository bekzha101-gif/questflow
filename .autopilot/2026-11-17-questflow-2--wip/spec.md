# Спецификация: QuestFlow 2.0

## Задача
«Система отличная, но я ей не пользуюсь регулярно: теряюсь в панели, забываю зайти на сайт, прокрастинирую». Бакыт работает 6 часов в день (3 блока по 2 ч, отдых по 20 мин, первый блок сразу после подъёма в 8–9), пятница — день полного восстановления без интернета. Ведёт 5 YouTube-каналов (+4 новых в планах), цель ноября — 40 каналов с автоматизацией. Сейчас таймер — будильник на планшете, данные — только в браузере Mac, напоминаний нет, AI не видит истории.

## Решение
1. **Сайт** (главное место): 5 понятных разделов вместо 8 — Сегодня · Цели · Каналы · Здоровье · Прогресс. Лишнее удалено, баги починены.
2. **Таймер 120/20** на сайте: не сбрасывается, сам ведёт цикл из 3 блоков, перед блоком — выбор задачи, после — «готово / % / бросил — почему», итог дня.
3. **Цели** месяц → 4 недели → шаги → дни, с архивом по месяцам.
4. **Big Data**: свои сферы и критерии, шаблон БАДов, график оценки дня с дельтой и причинами.
5. **Каналы**: статусы цветом, график публикаций, видео Монтаж → Проверка → Опубликовано, напоминания заранее.
6. **Telegram-бот** на этом компьютере: утро коротко, уведомления таймера, вечерний разговор 21:00 (текст или голос), отчёты недели и месяца; сам записывает ответы в данные.
7. **AI-аналитик** (Claude по подписке Max): разбор дня/недели/месяца, память о прошлом, причины спадов.
8. **Геймификация заново**: золото за часы фокуса, уровни (в т.ч. от дохода), ачивки, серии, жёсткие штрафы, магазин наград Бакыта.
9. Все данные — в Supabase (сайт и бот видят одно), перенос из браузера без потерь.

Нумерация меток: `R##` — бриф, `R##.n` — проработка, `G##` — позже от пользователя, `A## → R##` — добавление.

## Решения по реализации
- **Фронтенд** остаётся React 19 + TS + Vite + Tailwind 4 (существующий стек; переписывать нет причины). Тёмная тема, Linear/Raycast-минимализм, без эмодзи в интерфейсе.
- **Хранилище — Supabase**, новая миграция `002_questflow2.sql`: текстовые id, отдельные таблицы на сущности (задачи, цели, недели, шаги, сессии фокуса, состояние таймера, дни Big Data, настройки Big Data, каналы, видео, доход, события наград, ачивки, настройки бота, память AI, ключ-значение для прочего). RLS `auth.uid() = user_id` с `WITH CHECK`. Почему: бот и сайт пишут одновременно — построчные таблицы не затирают друг друга, как один JSON-документ.
- **Синк** переписан: модуль `data` с локальным кешем (localStorage) + очередью отправки + Realtime-подпиской. Почему: офлайн-first сохраняется, а бот видит свежие данные.
- **Перенос** из старых ключей `questflow_*` в новые таблицы — функция на сайте при входе (сначала JSON-бэкап). Почему: живые данные только в браузере Mac, и прислать файл пользователь не хочет.
- **Сервер** — Node.js 22 + TypeScript в папке `server/` этого репозитория: Telegram через grammY (long polling — не нужен открытый порт), расписания node-cron с `Asia/Bishkek`, Supabase через service-role ключ из `server/.env`. Почему не Supabase Edge Functions: там нельзя вызвать Claude по подписке и бесплатный Whisper на видеокарте; работают по таймеру, но разговор с состоянием и голос — неудобно и платно.
- **Голос** — faster-whisper (Python, CUDA, модель `medium`/`large-v3-turbo`) как отдельный процесс, который вызывает сервер. Бесплатно, RTX 2060 справляется.
- **AI** — `claude -p` (подписка, без `--bare`), JSON-вывод, промпт из среза данных + `ai_memory`. Запас — Anthropic API, если пользователь сам впишет `ANTHROPIC_API_KEY`. Нагрузка: ~1 анализ в день + 1 в неделю + 1 в месяц + разбор скриншота сна → малая доля лимитов Max; расход идёт из общего пула подписки.
- **Автозапуск** — задача Планировщика Windows «при запуске системы» под пользователем Administrator (нужен вход Claude этого пользователя) + обёртка, перезапускающая процесс при падении.
- **Время** — одна функция «сегодня по Бишкеку» на сайте и на сервере; везде вместо `toISOString().split('T')[0]`.
- **Тесты** — Vitest для чистых модулей (геймификация, цели, расписание каналов, таймер, Big Data-аналитика, время); сервер — Vitest на сценарии разговора с подменой Telegram/Supabase/Claude.
- **Стоимость в месяц**: $0 сверх подписки Max (сервер свой, Whisper локальный, Supabase Free до 500 МБ). Запасной API, если включить: ≈ $3–10/мес.

## Вне рамок
| Требование | Почему не сейчас |
|---|---|
| Инструменты из целей ноября (автоклонирование каналов, анализ ниши, поиск трендов, автовыкладка) | пользователь: «просто как цель отслиживаем прогерсс а инструменты итд в этом проекте не делаем» — заносятся только как цели |
| Управление таймером из Telegram | пользователь: «таймер работал только в сайте а не в тг» |
| Автоматическое получение сна из Sleep Cycle | на Android нет серверного доступа; заменено скриншотом (история 50) |
| Web Push на Android/Mac при закрытом сайте | закрыт Telegram-уведомлениями |
| Google Calendar / Google Fit / .ics | не трогаются: остаются как есть, в навигацию не выносятся |
| Смена системного часового пояса Windows | системная настройка компьютера — делает пользователь сам при желании |
