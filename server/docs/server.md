# Сервер QuestFlow на этом компьютере

Telegram-бот и расписания (Node 22 + TypeScript, папка `server/`). Работает 24/7 на этом компьютере. Время везде по Бишкеку (`shared/time.ts`), системный часовой пояс Windows менять не нужно.

## Установка (один раз)

1. Миграция `supabase/migrations/002_questflow2.sql` должна быть применена к базе Supabase.
2. В PowerShell:
   ```
   cd server
   npm install
   npm run setup
   ```
   Установщик по шагам объяснит, как создать бота в @BotFather, и спросит:
   - `TELEGRAM_BOT_TOKEN` — токен бота;
   - `SUPABASE_URL` — адрес проекта;
   - `SUPABASE_SERVICE_ROLE_KEY` — секретный ключ (только на этом компьютере, никогда на сайте);
   - `OWNER_USER_ID` — твой UID в Supabase;
   - `ANTHROPIC_API_KEY` — по желанию, запасной путь для анализа.

   Каждый ключ проверяется сразу. Значения пишутся в `server/.env` (он в `.gitignore`, в git не попадает). В конце нажми Start в боте: установщик привяжет твой чат и пришлёт первое сообщение.
3. Автозапуск: PowerShell **от имени администратора**:
   ```
   powershell -ExecutionPolicy Bypass -File server\scripts\install-service.ps1 -StartNow
   ```
   Создаётся задача Планировщика «QuestFlow Server»: запуск при включении компьютера под текущим пользователем, без входа в систему. Внутри — `scripts\run.ps1`: если бот упал, он поднимается через 10 секунд; если упал сам `run.ps1`, Планировщик перезапускает задачу через 1 минуту.

## Каждый день

- Логи: `server\logs\server-ГГГГ-ММ-ДД.log` (вывод бота) и `run-ГГГГ-ММ-ДД.log` (перезапуски). Хранятся 30 дней.
- Бэкапы: каждую ночь в 03:00 — `server\backups\questflow-ГГГГ-ММ-ДД.json` со всеми таблицами. Хранятся 60 дней.

## Перезапуск и остановка

```
Stop-ScheduledTask  -TaskName "QuestFlow Server"
Start-ScheduledTask -TaskName "QuestFlow Server"
```
После обновления кода: `cd server; npm install; npm run build`, затем остановить и запустить задачу.

Запустить в окне (для проверки), предварительно остановив задачу: `cd server; npm run build; npm start`.

Удалить автозапуск: `powershell -ExecutionPolicy Bypass -File server\scripts\install-service.ps1 -Uninstall` (от администратора).

## Что бот делает

| Когда (Бишкек) | Что |
|---|---|
| 8:00, кроме пятницы | одно короткое сообщение: главная задача дня и первый блок; затем до 3 напоминаний о публикациях |
| каждые 30 с | таймер: «пора на отдых, ты проработал Xч Yм», «отдых закончился» — по одному разу |
| время будильника | будильники здоровья из раздела «Здоровье» |
| 21:00 | вечерний разговор; в четверг перед ним — «завтра восстановление» |
| 22:00 | одно напоминание, если вечер пропущен |
| воскресенье / последний день месяца | отчёт недели / месяца |
| 03:00 | бэкап |
| пятница | бот молчит |

Бот отвечает только владельцу: чат привязывается первым `/start` (это делает установщик). Всем остальным бот отвечает «Этот бот приватный.».

## Если что-то не так

- «Не заданы переменные в server/.env» в логе — запусти `npm run setup` ещё раз (Enter оставляет прежние значения).
- Бот молчит — проверь задачу: `Get-ScheduledTask "QuestFlow Server" | Get-ScheduledTaskInfo`, затем лог за сегодня.
- Сменить токен бота: `npm run setup`, затем перезапустить задачу.
